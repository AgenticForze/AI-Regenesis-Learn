## TL;DR

Chapter 3.2 established that BERT-style models compute contextual representations from a whole
sequence, but did not say exactly what task they are trained to perform while doing it. There are
three dominant **language modeling objectives**, and the choice between them is the single biggest
factor in what a model ends up naturally good at. **Causal (autoregressive) language modeling**
predicts each next token from only the tokens before it, which is what makes open-ended text
generation possible. **Masked language modeling** hides random tokens and predicts them from full
bidirectional context, which produces strong representations for understanding tasks but no natural
way to generate new text. **Sequence-to-sequence (seq2seq)** modeling reads one full sequence with a
bidirectional encoder and generates a separate output sequence with a causal decoder, which is the
natural fit for transformation tasks like translation and summarization. Chapter 3.4 covers the model
families (GPT, BERT, T5) built around exactly these three objectives.

## High-Level Explanation

Picture the sentence "the customer's account was overdrawn." A **causal** model reads left to right
and, at each position, is only allowed to see what came before it: given "the customer's account was,"
it predicts "overdrawn" next, the way autocomplete predicts the next word as you type. A **masked**
model instead sees the whole sentence at once, except a few words have been blanked out ("the
customer's [MASK] was overdrawn"), and it fills in the blank using context from both sides,
similar to a cloze test. A **seq2seq** model does something different again: it reads an entire input
sequence (say, a sentence in English) and then generates a full, separate output sequence (a French
translation), one token at a time, while also being allowed to look back at the input it already fully
read.

These are not just three flavors of the same idea. They lead to models with genuinely different
natural strengths: causal models are the natural choice for open-ended generation, masked models are
the natural choice for classification and extraction tasks that need a rich understanding of a fixed
piece of text, and seq2seq models are the natural choice for input-to-output transformation tasks.

## Deep-Dive Explanation

**Causal language modeling, formally.** The objective maximizes the log-likelihood of each token
given every token before it: sum over t of log P(x_t | x_1, ..., x_(t-1)). Mechanically, this is
enforced with the **causal mask** from chapter 2.5: at position t, the self-attention computation
sets the attention score to negative infinity for every position after t, before the softmax, so no
information from future tokens can leak into the current prediction. At inference time this objective
has a direct consequence: generation is inherently sequential. A causal model produces one token,
appends it to the input, and repeats, since it has no other mechanism for producing text; there is no
way to "generate the whole sentence at once."

**Masked language modeling, formally, and BERT's specific recipe.** BERT's pretraining objective
randomly selects about 15% of input token positions and trains the model to predict the original
token at each selected position from the full bidirectional context. The specific replacement recipe
matters and is easy to gloss over: of the selected positions, 80% are replaced with a literal
`[MASK]` token, 10% are replaced with a random other token from the vocabulary, and 10% are left
unchanged. This mixture exists to reduce a mismatch between pretraining and downstream fine-tuning:
the `[MASK]` token never appears in real fine-tuning input, so always masking 100% of selected
positions would train the model to rely on a token it will never see again after pretraining; mixing
in random and unchanged tokens forces the model to keep building a genuine contextual representation
for every position, not only the ones it can detect are masked. BERT's original paper also trained a
second, auxiliary objective, next sentence prediction (predicting whether two given text spans were
truly adjacent in the source corpus), which later work (Liu et al.,
[*RoBERTa: A Robustly Optimized BERT Pretraining Approach*](https://arxiv.org/abs/1907.11692), 2019)
found contributed little and dropped, keeping masked language modeling alone as the pretraining
objective. A masked LM has no natural generation mechanism: it predicts a fixed, already-chosen set
of positions in a fixed-length input, not an open-ended continuation.

**Seq2seq, formally: two attention mechanisms doing different jobs.** A seq2seq model pairs a
bidirectional encoder (structurally similar to BERT's encoder, attending both directions over the
full input) with a causal decoder (structurally similar to a causal LM's decoder, attending only to
prior output tokens via a causal mask). The decoder adds a second attention mechanism beyond the
self-attention chapter 2.5 already covered: **cross-attention**, where each decoder position's query
vectors attend over the encoder's output states as keys and values, rather than over other decoder
positions. This is the specific mechanism that lets the decoder condition each generated token on the
entire input sequence the encoder already processed. Training uses **teacher forcing**: at each
decoder step during training, the ground-truth previous output token is fed in as input, regardless of
what the model itself would have predicted, which makes training parallelizable across positions but
creates **exposure bias**, a mismatch where the model never practices recovering from its own mistakes
during training, since at inference time it must feed back its own (possibly wrong) prior predictions
instead of the ground truth. T5 (Raffel et al.,
[*Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer*](https://arxiv.org/abs/1910.10683),
2020) demonstrated that this seq2seq architecture, combined with a span-corruption pretraining
objective (masking contiguous spans rather than individual tokens, and having the decoder generate
just the missing spans), can be cast as a single unified format, "text-to-text," where every task,
classification included, is reframed as generating a text output from a text input.

**Evaluating a language model: perplexity.** Causal and masked language models are typically compared
using **perplexity**, defined as the exponential of the average per-token cross-entropy loss over a
held-out set: perplexity = exp( -(1/N) * sum of log P(x_t | context) ). Lower perplexity means the
model assigned higher probability to the actual held-out tokens, on average; perplexity is
interpretable as the model's effective average branching factor, roughly "how many equally likely
next tokens did the model act as if there were," at each position.

```python
# Illustrative: perplexity from per-token cross-entropy loss (not a real model,
# just the arithmetic relationship described above).
import math

per_token_losses = [0.8, 1.2, 0.5, 2.1, 0.9]  # cross-entropy loss at each token
avg_loss = sum(per_token_losses) / len(per_token_losses)
perplexity = math.exp(avg_loss)
print(f"average loss: {avg_loss:.3f}, perplexity: {perplexity:.3f}")
```
