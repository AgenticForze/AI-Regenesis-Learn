## TL;DR

Chapter 1.2 named "machine learning" as one layer in the AI taxonomy: logic learned from data via
a loss function and an optimizer. This chapter opens that layer up. What a model learns from, and
how it's told whether it's doing well, splits into three paradigms: supervised learning (learn
from labeled examples), unsupervised learning (find structure with no labels at all), and
reinforcement learning (learn from a reward signal earned by acting in an environment). Most
production ML systems combine more than one of these, often in the same pipeline.

## High-Level Explanation

**Supervised learning** starts from labeled examples: pairs of an input and the correct output,
like a set of past loan applications each labeled "defaulted" or "repaid." The model learns a
mapping from input to output and is graded against the labels it was given. Supervised problems
split into two shapes: classification, where the output is one of a fixed set of categories (fraud
or not fraud), and regression, where the output is a continuous number (the price of a house).

**Unsupervised learning** starts from the same kind of input data but with no labels at all. There
is no "correct answer" to be graded against; the goal is to find structure that was already there.
Clustering groups similar records together (segmenting customers by behavior); dimensionality
reduction compresses many correlated features into a few informative ones (compressing thousands of
sensor readings into a handful of components for visualization); anomaly detection flags records
that don't resemble the rest of the data, without ever having been shown a labeled example of what
"anomalous" looks like.

**Reinforcement learning (RL)** doesn't start from a fixed dataset at all. An agent takes actions
inside an environment, observes what happens, and receives a reward signal, a number saying how
good or bad the outcome was, then adjusts its behavior to earn more reward over time. AlphaGo Zero
(Silver et al.,
[*Mastering the Game of Go without Human Knowledge*](https://www.nature.com/articles/nature24270),
*Nature*, 2017) is the cleanest example: starting from random play with no human game data at all,
nobody labels the "correct" move in a given board position, but the system improves purely from
whether it eventually wins or loses against itself.

![Three data flows: supervised learning compares a prediction to a label, unsupervised learning looks for structure with no label to compare against, and reinforcement learning loops an agent's actions through an environment that returns a new state and a reward](/img/illustrations/1-3-three-paradigms.svg)

The dividing question across all three: what feedback does the model get, and where does that
feedback come from? A human-supplied label, no feedback signal at all beyond the data's own
structure, or a reward earned by interacting with a live environment.

## Deep-Dive Explanation

**Supervised learning, formally.** Given a labeled dataset of examples (x₁, y₁) through (xₙ, yₙ),
the goal is to learn a function f(x) that approximates y for inputs the model hasn't seen yet,
found by minimizing a loss function that penalizes wrong predictions on the training set. When y is
categorical, this is classification; when y is a real number, it's regression. The label y is what
distinguishes supervised learning from the other two paradigms: it's the ground truth the model is
directly graded against at every training step.

**Unsupervised learning, formally.** There is no y. The model instead learns something about the
structure of P(x), the distribution the inputs themselves came from. Clustering algorithms like
k-means (the term was coined by MacQueen,
[*Some Methods for Classification and Analysis of Multivariate Observations*](https://projecteuclid.org/ebooks/berkeley-symposium-on-mathematical-statistics-and-probability/Some-methods-for-classification-and-analysis-of-multivariate-observations/chapter/Some-methods-for-classification-and-analysis-of-multivariate-observations/bsmsp/1200512992),
1967) partition x into groups that minimize within-group distance. Dimensionality-reduction
methods like PCA, which traces to Pearson,
[*On Lines and Planes of Closest Fit to Systems of Points in Space*](https://www.tandfonline.com/doi/abs/10.1080/14786440109462720),
1901 (the geometric best-fit-line problem), and to Hotelling,
[*Analysis of a Complex of Statistical Variables into Principal Components*](https://psycnet.apa.org/doi/10.1037/h0071325),
1933 (who coined "principal components" and gave the eigenvector-based formulation used today),
find the directions of greatest variance in x and re-express the data along them. Neither
technique has a label to check its answer against; success is judged by how useful or compact the
discovered structure turns out to be, which is a softer, more subjective bar than a classifier's
accuracy on held-out labels.

**Reinforcement learning, formally.** RL is usually formalized as a Markov Decision Process: a set
of states S, actions A, a transition function describing how the state changes given an action, and
a reward function R that scores each transition (Sutton and Barto,
[*Reinforcement Learning: An Introduction*](http://incompleteideas.net/book/the-book-2nd.html),
2nd ed., 2018). "Agent" here is RL's own decades-older usage: any decision-maker that perceives a
state and chooses an action, whether or not it involves a language model at all (a thermostat's
control loop or a robotic arm's controller both count). It's a broader use of the word than the
glossary's Agent entry, which is scoped specifically to LLM-based systems; chapter 1.2's agentic-AI
layer is the narrower, generative-model-wrapping case of this same general idea. Chapter 1.2 also
notes that RL itself is not one of that chapter's five layers; it is an optimization technique that
can train a system at any of them, tabular, deep, or generative, so "reinforcement learning" and
"agentic AI" answer different questions (how a policy was optimized, versus whether a system acts
in a perceive/decide/act loop) and a given system can be described by either, both, or neither. The
agent learns a policy, a rule for
choosing actions, that maximizes its expected cumulative reward over time, not just the immediate
reward at each step. Two properties make this
fundamentally different from supervised learning rather than just a variant of it. First, there is
no per-step ground truth: nobody labels the single correct action for a given state, only a reward
that may not reveal how good that action really was until many steps later (credit assignment).
Second, the agent's own actions determine what data it sees next, which supervised learning never
has to deal with: a classifier's training set doesn't change based on what the classifier predicts,
but an RL agent that explores a bad strategy generates its own bad training data as a consequence.

**Where the boundary blurs: self-supervised learning.** Large language model pretraining, next-token
prediction over raw text, looks unsupervised (no human labeled anything) but is mechanically
supervised: the label for each training example is the actual next token in the text, and the model
is graded against it with an ordinary loss function. This is called self-supervised learning: the
labels are real, they're just generated automatically from the data itself instead of by a human
annotator. Some researchers treat self-supervised learning as its own paradigm rather than a variant
of supervised learning, since it needs no human-curated labels and is typically used to learn
general-purpose representations rather than one specific task; this chapter uses the mechanical
framing because it's the one that explains why the training loop looks identical to ordinary
supervised learning. Next-token prediction specifically is the paradigm behind autoregressive
language models; other parts of the generative AI layer covered in chapter 1.2, such as diffusion
image models, use a different self-supervised target (predicting the noise added to an image) rather
than a next-token label, but the same mechanical pattern applies: an automatically generated label,
checked with an ordinary loss.

**A common misclassification worth naming: reward hacking is not the same failure as label leakage.**
A supervised model trained on leaked labels performs well during training and poorly in production
because it learned a shortcut that won't exist at inference time. An RL agent that hacks its reward
function performs exactly as well as its reward function measures. The problem is that the reward
function was an imperfect proxy for what its designers actually wanted (Amodei et al.,
[*Concrete Problems in AI Safety*](https://arxiv.org/abs/1606.06565),
2016). A hypothetical often used to illustrate the pattern: a cleaning robot rewarded for "not
seeing any mess" could learn to turn off its own camera rather than clean. Nothing was leaked; the
objective itself was wrong. This distinction matters
directly for Phase 7's coverage of RLHF (reinforcement learning from human feedback), where a reward
model trained on human preference comparisons (Christiano et al.,
[*Deep Reinforcement Learning from Human Preferences*](https://arxiv.org/abs/1706.03741),
2017) is itself a supervised model, whose imperfections become exactly the kind of reward-hacking
surface described above once an RL policy is optimized against it.
