## TL;DR

Four areas of math do essentially all the work behind every chapter so far and every chapter still
to come. Linear algebra is the language a model's inputs and parameters are written in. Probability
is how a model expresses and reasons about uncertainty. Statistics is how a practitioner decides
whether a result is real or noise. Optimization is the mechanism, almost always gradient descent,
by which a model actually learns. None of this requires proving theorems; it requires knowing what
each tool is for well enough to recognize when a result is suspicious.

## High-Level Explanation

**Linear algebra** is how data is represented. A single example, a house's square footage, bedroom
count, and age, is a vector: an ordered list of numbers. A full dataset is a matrix: one row per
example, one column per feature. A model's parameters (the weights in linear regression, chapter
1.5, or a neural network layer) are also vectors and matrices, and a prediction is usually computed
as a matrix multiplication between the two. Two operations recur constantly: the dot product, which
measures how aligned two vectors are, and matrix multiplication, which is really many dot products
computed at once.

**Probability** is how a model represents not knowing something for certain. A classifier's output
is not "spam" or "not spam", it is a probability, such as 0.92, that the email is spam. Bayes'
theorem is the formal rule for updating a probability estimate when new evidence arrives, and it
underlies Naive Bayes (chapter 1.2), Bayesian approaches to A/B testing, and the reasoning a
clinician uses when interpreting a diagnostic test result.

**Statistics** is how a practitioner decides whether an observed difference is real. If model B
scores 0.2 percentage points higher than model A on a test set, is that a genuine improvement or
random variation from which examples happened to land in the test split? Descriptive statistics
(mean, variance, correlation) summarize data; inferential statistics (hypothesis tests, confidence
intervals) quantify how much an estimate could plausibly be due to chance.

**Optimization** is how learning actually happens. Training a model means searching for the
parameter values that minimize a loss function, a number that measures how wrong the model's
predictions currently are. Gradient descent is the standard search procedure: compute the
direction that most steeply increases the loss (the gradient), then take a small step in the
opposite direction, repeatedly, until the loss stops improving.

## Deep-Dive Explanation

**Linear algebra, formally.** A vector x in ℝᵈ is an ordered list of d real numbers. The dot
product of two vectors, x · y = Σᵢ xᵢyᵢ, is large and positive when the vectors point in similar
directions, near zero when they are roughly perpendicular (unrelated), and negative when they point
in opposite directions. Cosine similarity, x · y / (‖x‖‖y‖), normalizes the dot product by each
vector's length, so it measures direction alone, independent of magnitude, which is why it is the
standard similarity measure for text and recommendation embeddings regardless of how long a
document is. Matrix multiplication generalizes the dot product: multiplying a data matrix X (rows
are examples, columns are features) by a weight vector w computes every example's weighted sum in
one operation, which is exactly how linear regression, logistic regression, and a single neural
network layer compute their output. Eigenvectors and eigenvalues decompose a square matrix into the
directions it stretches (eigenvectors) and by how much (eigenvalues); Principal Component Analysis
uses the eigenvectors of a dataset's covariance matrix to find the directions of greatest variance,
the basis for dimensionality reduction. The L1 and L2 norms, ‖w‖₁ = Σ|wᵢ| and ‖w‖₂ = √(Σwᵢ²),
measure a vector's overall size and are exactly what L1 and L2 regularization (chapter 1.4) penalize
to control model complexity.

**Probability, formally.** Bayes' theorem states P(A | B) = P(B | A) · P(A) / P(B): the probability
of A given evidence B equals the probability of that evidence given A, weighted by how likely A was
before seeing any evidence (the prior), normalized by how likely the evidence is overall. The
counterintuitive case that trips up even careful reasoning is a rare-condition diagnostic test:
even a test with 99% sensitivity and 99% specificity produces mostly false positives when the
condition's true prevalence (the prior) is very low, because the number of healthy people
multiplied by a 1% false-positive rate can exceed the number of truly sick people multiplied by a
99% true-positive rate. This is the same base-rate reasoning that makes accuracy misleading on
imbalanced classes (chapter 1.6). A random variable's expectation, E[X] = Σₓ x · P(X = x), is its
long-run average value, and its variance, Var(X) = E[(X − E[X])²], measures how spread out it is
around that average, the same variance that appears in the bias-variance tradeoff (chapter 1.4).
The Gaussian (normal) distribution recurs constantly because many real-world quantities that result
from summing many small independent effects converge to it (the Central Limit Theorem), and because
several standard loss functions, including mean squared error, are the mathematically correct
choice specifically when a model's errors are assumed to be Gaussian-distributed.

**Statistics, formally.** A p-value is the probability of observing a difference at least as
extreme as the one measured, if there were actually no true difference at all; a small p-value
(conventionally below 0.05) is evidence against "no difference," not proof of a specific effect
size. A confidence interval gives a range of plausible values for the true effect and is often more
useful than a p-value alone, because a statistically significant result can still have a
practically tiny effect size, and a wide confidence interval signals that a point estimate is
unreliable even if it clears the significance threshold. Correlation, the standardized covariance
between two variables scaled to [−1, 1], measures a linear relationship, not causation; two
variables can be strongly correlated because one causes the other, because both are driven by a
third factor, or by coincidence in a small sample. Model comparison in production, deciding whether
a new model actually outperforms the one it replaces, is a direct application of hypothesis testing
to the evaluation metrics from chapter 1.6, and is exactly why A/B tests need a large enough sample
before a result is trustworthy.

**Optimization, formally.** Gradient descent updates parameters with the rule θ ← θ − η∇L(θ), where
∇L(θ) is the gradient of the loss function with respect to the parameters (the direction of
steepest increase) and η (eta) is the learning rate, a small positive number controlling step size.
Too large a learning rate causes the loss to oscillate or diverge instead of decreasing; too small a
learning rate converges reliably but slowly. Stochastic Gradient Descent (SGD) computes the
gradient on a small random batch of examples rather than the full dataset at every step, trading a
noisier gradient estimate for dramatically faster iteration, and that noise can itself help the
search escape shallow local minima. A convex loss surface (linear regression's squared-error loss
is convex) has exactly one minimum, so gradient descent is guaranteed to find it; a non-convex loss
surface (the loss landscape of a deep neural network) can have many local minima and saddle points,
so where training starts and how it is regularized materially affects where it ends up.
Backpropagation, the algorithm that trains neural networks, is not a separate technique from
gradient descent, it is the chain rule from calculus applied systematically to compute ∇L(θ) for
every parameter in a multi-layer network efficiently.
