## TL;DR

An RNN (2.4), even with LSTM or GRU gating, still processes a sequence one step at a time: step 50
cannot start until step 49 finishes, and information connecting two distant positions still has to
travel through every step in between. The Transformer removes recurrence entirely and replaces it
with **self-attention**: every position looks directly at every other position in a single step,
so the path length between any two positions is constant regardless of distance, and every
position in a sequence can be processed in parallel during training. Because attention alone has no
built-in sense of order, a **positional encoding** is added to each token's representation so the
model can recover word order. **Multi-head attention** runs several attention computations in
parallel with different learned projections, letting the model attend to different kinds of
relationships (say, syntactic agreement and topical relevance) at once. Stacked layers of
attention and a position-wise feedforward network, each wrapped in a residual connection (2.3) and
layer normalization, form the encoder and decoder stacks that make up the full architecture
(Vaswani et al., 2017).

## High-Level Explanation

**Self-attention** lets every word in a sequence directly weigh how relevant every other word is to
understanding it, and then builds a new representation for that word as a weighted combination of
all the others, weighted by that relevance. Reading "the animal didn't cross the street because it
was too tired," resolving what "it" refers to means the word "it" needs to attend strongly to
"animal" and weakly to everything else; self-attention computes exactly this kind of relevance
score between every pair of words in the sequence, all at once, rather than relying on a hidden
state that has been carried step by step from wherever "animal" appeared.

**Multi-head attention** runs this relevance-and-combine process several times in parallel, each
with its own learned set of projections, so different heads can specialize in different kinds of
relationships. One head might learn to track subject-verb agreement, another might track
coreference like the "it" example above, and another might track topical similarity; the model
learns what each head specializes in during training, nothing is hand-assigned.

Because self-attention treats a sequence as a set of positions to compare rather than a chain
processed in order, it has no inherent notion of which word came first, second, or last: shuffling
the input words would produce the same set of pairwise comparisons. A **positional encoding** is
added to each word's embedding before the first attention layer, injecting a signal that varies
with position so the model can recover order and relative distance between words.

The full architecture is organized as an **encoder** and a **decoder**. The encoder reads the
entire input sequence and builds a contextual representation of it, with every position attending
to every other input position. The decoder generates the output sequence one token at a time; at
each step it attends to the tokens it has already generated (masked so it cannot look ahead at
tokens it hasn't produced yet) and separately attends to the encoder's output, pulling in relevant
information from the input.

## Deep-Dive Explanation

**Scaled dot-product attention, formally.** Every input position's embedding is linearly projected
into three vectors: a query Q, a key K, and a value V, using three learned weight matrices (W_Q,
W_K, W_V) shared across positions. Attention output is computed as:

Attention(Q, K, V) = softmax(QK^T / √d_k) · V

QK^T computes a similarity score between every query and every key (a dot product: higher when the
two vectors point in a similar direction), producing an n x n matrix of raw relevance scores for a
sequence of length n. Dividing by √d_k, where d_k is the dimensionality of the key vectors,
counteracts a specific problem: as d_k grows, dot products tend to grow large in magnitude purely
from summing more terms, which pushes the softmax into a region where its gradient is very small,
the same kind of saturated-gradient problem chapter 2.1 introduced for sigmoid activations. Scaling
keeps the values in a range where softmax gradients stay informative. Softmax then converts each
row of scores into a probability distribution over positions to attend to, and the result is a
weighted sum of value vectors V using those probabilities as weights.

**Multi-head attention** runs h independent copies of this computation in parallel, each with its
own W_Q, W_K, W_V projecting into a smaller dimension (d_model / h), then concatenates all h
outputs and applies one more learned projection W_O:

MultiHead(Q, K, V) = Concat(head_1, ..., head_h) · W_O, where head_i = Attention(Q·W_Q_i, K·W_K_i, V·W_V_i)

Splitting into h smaller heads costs roughly the same total compute as one large head, but gives
the model h separate subspaces in which to learn distinct relevance patterns rather than one
averaged pattern (Vaswani, Shazeer, Parmar, Uszkoreit, Jones, Gomez, Kaiser, and Polosukhin,
[*Attention Is All You Need*](https://arxiv.org/abs/1706.03762), NeurIPS, 2017). This mechanism
builds on an earlier, RNN-based attention mechanism that first showed a model could learn to focus
on relevant input positions rather than compressing an entire sequence into one fixed vector
(Bahdanau, Cho, and Bengio,
[*Neural Machine Translation by Jointly Learning to Align and Translate*](https://arxiv.org/abs/1409.0473),
ICLR, 2015); the Transformer's contribution was showing that attention alone, without any
recurrence at all, is sufficient.

**Positional encoding.** The original Transformer adds a fixed, deterministic signal to each
position's embedding using sine and cosine functions at different frequencies:

PE(pos, 2i) = sin(pos / 10000^(2i/d)), PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

where pos is the position in the sequence and i indexes the embedding dimension. Because sine and
cosine at a fixed frequency have the property that PE(pos+k) can be expressed as a linear function
of PE(pos), the model can in principle learn to attend by relative position, not just absolute
position. Later Transformer variants often use learned positional embeddings or other schemes
instead, but the underlying requirement, that some position-dependent signal must be injected
since attention itself has none, holds across all of them.

**Masking.** The decoder's self-attention must not let a position attend to positions after it,
since at generation time those tokens do not exist yet. This is enforced by adding negative
infinity to the disallowed entries of the QK^T score matrix before the softmax, so their attention
weight becomes exactly zero. This is called a causal mask, and it is what makes decoder training
consistent with autoregressive generation at inference time.

**The full block.** Each encoder layer applies multi-head self-attention followed by a
position-wise feedforward network (two linear layers with a nonlinearity between them, applied
identically to every position), and both sublayers are wrapped in a residual connection (2.3) and
followed by layer normalization: output = LayerNorm(x + Sublayer(x)). Layer normalization
normalizes across a single position's feature dimensions rather than across a batch, which makes it
independent of batch size and well suited to sequences of varying length (Ba, Kiros, and Hinton,
[*Layer Normalization*](https://arxiv.org/abs/1607.06450), 2016). A decoder layer has the same two
sublayers plus a third: cross-attention, where queries come from the decoder's own
representation but keys and values come from the encoder's output, which is how the decoder pulls
information from the input sequence. The original architecture stacks 6 encoder layers and 6
decoder layers, though later models vary this substantially. Before any of this, raw text is split
into subword tokens (commonly by byte-pair encoding) so that both common whole words and rare or
unseen words can be represented from a fixed, manageable vocabulary (Sennrich, Haddow, and Birch,
[*Neural Machine Translation of Rare Words with Subword Units*](https://aclanthology.org/P16-1162/),
ACL, 2016).

**Compute tradeoff.** Self-attention's cost per layer scales as O(n^2 · d) for a sequence of length
n and dimension d, since every position compares against every other position, versus an RNN
layer's O(n · d^2). For the sequence lengths common in the original Transformer's experiments this
favored attention, since it runs in parallel across positions rather than n sequential steps; for
very long sequences the quadratic term in n becomes the dominant cost, which is why long-context
efficiency became an active research area in the years after this architecture was introduced.

```python
import numpy as np

def softmax(x, axis=-1):
    x = x - np.max(x, axis=axis, keepdims=True)  # numerical stability
    e = np.exp(x)
    return e / np.sum(e, axis=axis, keepdims=True)

def scaled_dot_product_attention(Q, K, V, mask=None):
    """Q, K, V: arrays of shape (seq_len, d_k). mask: optional (seq_len, seq_len) of 0/1."""
    d_k = Q.shape[-1]
    scores = Q @ K.T / np.sqrt(d_k)          # (seq_len, seq_len) raw relevance scores
    if mask is not None:
        scores = np.where(mask == 0, -np.inf, scores)   # causal mask: block future positions
    weights = softmax(scores, axis=-1)        # each row sums to 1
    return weights @ V, weights               # weighted sum of values, and the weights themselves
```
