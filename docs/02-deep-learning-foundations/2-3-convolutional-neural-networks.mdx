## TL;DR

The fully connected MLP from 2.1 treats every input feature as independent, which is wasteful for
images: a photo's pixels have spatial structure, and the pattern that makes something an edge or a
texture looks the same whether it appears in the top-left or bottom-right corner. A convolutional
neural network (CNN) exploits that structure with a small filter that slides across the entire
image, reusing the same weights at every position instead of learning a separate weight for every
pixel location. This parameter sharing makes CNNs dramatically more efficient than a fully
connected network on image-like data, and stacking convolution and pooling layers builds a
hierarchy of features automatically, from edges, to textures, to object parts, to whole objects.

## High-Level Explanation

A **convolution** slides a small grid of learned numbers, called a filter or kernel (commonly 3x3
or 5x5), across the input image. At each position, it multiplies the filter's values against the
pixels underneath it, sums the results, and produces one output value; sliding the filter across
every position produces a full 2D grid of outputs called a **feature map**. Each filter learns to
detect one specific local pattern, an edge at a particular angle, a corner, a patch of a specific
texture, and because the same filter is reused at every position, the network learns that pattern
once and can recognize it anywhere in the image. A convolutional layer typically applies many
filters in parallel, each producing its own feature map, so the layer's output has many "channels,"
one per filter.

**Pooling** downsamples a feature map, most commonly by taking the maximum value in each small
non-overlapping region (max pooling). This reduces the spatial size of the data flowing through the
network, cuts the amount of computation needed in later layers, and gives the network some
tolerance to a pattern shifting by a few pixels, since the same maximum survives a small
translation. A typical CNN alternates convolution (plus a nonlinear activation, chapter 2.1) and
pooling several times: each stage's feature maps become the next stage's input, so early layers
detect simple local patterns like edges, and later layers, working on the already-simplified output
of earlier layers, combine those into progressively more complex patterns: textures, then object
parts, then whole objects.

## Deep-Dive Explanation

**The convolution operation, formally.** For a filter K of size FxF and an input region of the
same size starting at position (i, j), the output feature map value is
output[i,j] = Σm Σn input[i+m, j+n]·K[m,n] + b, summing over every offset (m, n) inside the filter,
followed by an activation function exactly as in chapter 2.1's z = Σwx + b. Two settings control how the
filter moves: **stride**, the number of pixels the filter shifts between positions (stride 1 moves
one pixel at a time; stride 2 skips every other position, halving the output size), and
**padding**, whether zeros are added around the input's border so the filter can be centered on
edge pixels ("same" padding, which keeps the output the same spatial size as the input) or not
("valid" padding, which shrinks the output). The output size along one dimension is
floor((W - F + 2P) / S) + 1, where W is the input size, F the filter size, P the padding, and S the
stride.

**Parameter sharing is the entire efficiency argument.** A fully connected layer mapping a modest
224x224x3 image to a single 1,000-unit hidden layer needs 224x224x3x1000, over
150 million weights, for that one layer alone. A convolutional layer with 64 filters of size 3x3
over the same 3-channel input needs only 3x3x3x64 + 64, about 1,792 weights, regardless of
how large the input image is, because the same filter weights are reused at every spatial position
rather than each position getting its own independent set of weights. This is a strong inductive
bias (1.5): the network assumes a useful local pattern is worth detecting the same way everywhere in
the image, which is true for most natural images and is exactly the assumption a fully connected
layer does not make.

**Receptive field.** A single unit in a feature map several layers deep is not looking at the whole
original image directly; it is a function of a specific, growing region of the input, called its
receptive field. Each additional convolution or pooling layer expands the receptive field of the
units that follow it, which is why early layers detect small, local patterns (edges) and later
layers, whose units each depend on a much larger region of the original image, detect larger, more
composite patterns (object parts, whole objects).

**LeNet-5**, one of the earliest successful CNNs, applied this alternating convolution-and-pooling
structure to handwritten digit recognition, trained end-to-end with backpropagation (2.2), and
demonstrated that a network could learn its own feature detectors directly from pixels rather than
requiring hand-engineered features (LeCun, Bottou, Bengio, and Haffner,
[*Gradient-Based Learning Applied to Document Recognition*](https://ieeexplore.ieee.org/document/726791),
*Proceedings of the IEEE*, 1998). **AlexNet** scaled the same core idea substantially deeper and
wider, trained on GPUs, and won the 2012 ImageNet competition by a wide margin over
non-deep-learning approaches, using ReLU activations (2.1) instead of sigmoid/tanh and dropout for
regularization; its result is widely credited with triggering the deep learning boom in computer
vision (Krizhevsky, Sutskever, and Hinton,
[*ImageNet Classification with Deep Convolutional Neural Networks*](https://papers.nips.cc/paper/4824-imagenet-classification-with-deep-convolutional-neural-networks),
NeurIPS, 2012). Simply stacking more convolutional layers eventually stopped helping and started
hurting accuracy, even on the training set, a degradation problem distinct from overfitting.
**ResNet** solved this with residual (skip) connections: instead of forcing a stack of layers to
learn a full output mapping H(x) directly, each block learns a residual F(x) = H(x) - x that is
added back to its own input, output = F(x) + x, so a block that has nothing useful to add can more
easily learn to approximate zero and pass its input through unchanged, which is much closer to what
gradient descent starting from a near-zero initialization has to reach anyway (He, Zhang, Ren, and
Sun,
[*Deep Residual Learning for Image Recognition*](https://arxiv.org/abs/1512.03385),
CVPR, 2016). This let networks scale to over a hundred layers deep and improve accuracy further,
where plain stacked convolutional networks had already stopped improving.

```python
import numpy as np

def conv2d_single_channel(image, kernel, stride=1, padding=0):
    """A minimal, unoptimized 2D convolution for one input channel, one filter."""
    if padding > 0:
        image = np.pad(image, padding)
    h, w = image.shape
    kh, kw = kernel.shape
    out_h = (h - kh) // stride + 1
    out_w = (w - kw) // stride + 1
    output = np.zeros((out_h, out_w))
    for i in range(out_h):
        for j in range(out_w):
            region = image[i*stride:i*stride+kh, j*stride:j*stride+kw]
            output[i, j] = np.sum(region * kernel)  # this is the convolution's core operation
    return output

# A 3x3 vertical-edge-detecting filter applied to a 6x6 input
image = np.array([[0,0,0,1,1,1]]*6)
edge_filter = np.array([[1,0,-1],[1,0,-1],[1,0,-1]])
print(conv2d_single_channel(image, edge_filter))  # large-magnitude values mark the vertical edge column
```
