## TL;DR

A CNN (2.3) exploits spatial structure by reusing a filter across positions in an image. A
recurrent neural network (RNN) applies the same idea to time: it reuses the same weights at every
step of a sequence, carrying a running summary forward from one step to the next called the hidden
state. This makes RNNs a natural fit for text, time series, and sensor data, anything where order
matters. Plain RNNs struggle to remember information from many steps earlier, because
backpropagating through a long sequence multiplies the same shrinking or growing gradient factor
from chapter 2.2 many times over. LSTM and GRU cells add gating mechanisms specifically designed to
keep that gradient flowing over long sequences, which is why they, not plain RNNs, were the
practical default for sequence modeling for two decades before the Transformer (2.5).

## High-Level Explanation

A **recurrent neural network** processes a sequence one element at a time, and at each step it
combines the current input with a **hidden state** carried over from the previous step, producing a
new hidden state to pass forward. The same weights are reused at every time step, exactly as a
CNN's filter is reused at every spatial position, so the network learns one update rule and applies
it repeatedly rather than learning a separate rule for position 1, position 2, and so on. This
hidden state is the network's working memory: reading a sentence word by word, it is the running
summary of everything read so far, updated with each new word.

Plain RNNs are unreliable at carrying information across long gaps. Because the same recurrence is
applied at every step, "unrolling" a sequence of length T for training is mathematically like
having a T-layer-deep network (chapter 2.2's backpropagation runs through all T steps, called
backpropagation through time), and the vanishing/exploding gradient problem from 2.2 compounds over
however many steps separate a relevant piece of information from where it is needed. A plain RNN
trying to connect a pronoun to a subject mentioned forty words earlier is fighting the same
shrinking-gradient problem a 40-layer plain feedforward network would face. **LSTM** and **GRU**
cells were designed specifically to fix this by adding gates: small learned sub-networks that
control what information the cell keeps, discards, and outputs at each step, giving the gradient a
much more direct path across long sequences.

## Deep-Dive Explanation

**The plain RNN recurrence, formally.** At each time step t, a simple recurrent network computes
h_t = φ(W_hh·h_(t-1) + W_xh·x_t + b), where h_(t-1) is the previous hidden state, x_t is the current
input, W_hh and W_xh are weight matrices shared across every time step, and φ is typically tanh
(chapter 2.1). An output y_t, when one is needed at that step, is a further linear transformation of
h_t. This structure, a hidden state fed back into the same weights at the next step, was introduced
as the simple recurrent network for modeling sequential structure in language (Elman,
[*Finding Structure in Time*](https://onlinelibrary.wiley.com/doi/abs/10.1207/s15516709cog1402_1),
*Cognitive Science*, 1990). Training unrolls the recurrence across all T steps of a sequence and
applies backpropagation (2.2) through the resulting T-step computation graph, so the same weights
receive a gradient contribution from every time step, summed together.

**LSTM (Long Short-Term Memory)** adds a separate cell state c_t that runs through the sequence
largely unchanged except for gated additions and removals, alongside the hidden state h_t. Three
gates, each a sigmoid-activated function of the current input and previous hidden state (so each
gate outputs values between 0 and 1, acting as a soft on/off switch per dimension), control it: the
**forget gate** f_t = σ(W_f·[h_(t-1), x_t] + b_f) decides what fraction of the existing cell state to
keep; the **input gate** i_t = σ(W_i·[h_(t-1), x_t] + b_i) decides how much of a new candidate value
to add; and the **output gate** o_t = σ(W_o·[h_(t-1), x_t] + b_o) decides how much of the cell state
to expose as the hidden state. The cell state update, c_t = f_t·c_(t-1) + i_t·c~_t (where
c~_t is a tanh-activated candidate value), is largely additive rather than repeatedly multiplying
through a nonlinearity at every step, which gives the gradient a much shorter, more direct path
backward through time than a plain RNN's repeated matrix multiplication provides, directly
addressing the vanishing gradient problem chapter 2.2 introduced (Hochreiter and Schmidhuber,
[*Long Short-Term Memory*](https://dl.acm.org/doi/10.1162/neco.1997.9.8.1735),
*Neural Computation*, 1997).

**GRU (Gated Recurrent Unit)** simplifies this with two gates instead of three, and no separate cell
state: an **update gate** z_t controls how much of the previous hidden state to keep versus replace
with a new candidate, and a **reset gate** r_t controls how much of the previous hidden state
influences that new candidate. With fewer parameters than an LSTM cell of the same hidden size, a
GRU trains faster and often reaches comparable accuracy, though which one wins is task-dependent
enough that both remained common choices in practice (Cho, van Merrienboer, Gulcehre, Bahdanau,
Bougares, Schwenk, and Bengio,
[*Learning Phrase Representations Using RNN Encoder-Decoder for Statistical Machine Translation*](https://aclanthology.org/D14-1179/),
EMNLP, 2014).

**Bidirectional RNNs.** A standard RNN only sees a sequence in one direction, left to right, so its
hidden state at step t reflects everything before t but nothing after it. For tasks where the whole
sequence is available at once, rather than being generated one step at a time (classifying a
sentence's sentiment, tagging each word's part of speech), a bidirectional RNN runs two separate
RNNs, one forward and one backward over the sequence, and concatenates their hidden states at each
position, so every position's representation reflects context from both directions.

```python
import numpy as np

def rnn_step(x_t, h_prev, W_xh, W_hh, b):
    """One plain RNN time step: h_t = tanh(W_hh @ h_prev + W_xh @ x_t + b)."""
    return np.tanh(W_hh @ h_prev + W_xh @ x_t + b)

def lstm_step(x_t, h_prev, c_prev, params):
    """One LSTM time step, following the standard gate equations."""
    z = np.concatenate([h_prev, x_t])
    f_t = sigmoid(params['W_f'] @ z + params['b_f'])   # forget gate
    i_t = sigmoid(params['W_i'] @ z + params['b_i'])   # input gate
    o_t = sigmoid(params['W_o'] @ z + params['b_o'])   # output gate
    c_candidate = np.tanh(params['W_c'] @ z + params['b_c'])
    c_t = f_t * c_prev + i_t * c_candidate             # mostly additive cell update
    h_t = o_t * np.tanh(c_t)
    return h_t, c_t

def sigmoid(z):
    return 1 / (1 + np.exp(-z))
```
