## TL;DR

An autoregressive LLM (3.3, 4.1) computes an exact probability distribution over every possible next
token at each step, but that distribution alone does not produce text; a **decoding strategy** is the
algorithm that turns those probabilities into an actual chosen sequence. **Greedy decoding** always
picks the single highest-probability token; it is cheap and deterministic but, along with **beam
search**, which tracks several candidate sequences at once, tends toward repetitive, generic text
because maximizing likelihood at every step does not actually match how real human text is
distributed. **Temperature**, **top-k sampling**, and **nucleus (top-p) sampling** instead introduce
controlled randomness, producing text statistically closer to human writing at the cost of
determinism. **Speculative decoding** is a separate axis entirely: not a choice about which token to
pick, but a technique for producing the exact same output faster, using a small draft model to
propose several tokens that the full model verifies in one pass.

## High-Level Explanation

Picture a writer choosing the next word in a sentence one word at a time. A greedy writer always
picks the single most expected next word: after "the cat sat on the," that writer always says "mat,"
every single time, because "mat" is statistically the most likely continuation. This produces
technically fluent but flat, predictable prose. A writer using beam search keeps a handful of
competing draft sentences alive at once and only commits to the one that sounds best overall once a
few words have been written, which helps somewhat but still tends toward the same safe, expected
phrasing. A writer who actually samples rolls weighted dice for each word, occasionally choosing a
less expected but still plausible word, which is closer to how real human writing varies its
phrasing. Temperature controls how loaded those dice are: very loaded dice basically always land on
the top choice, ordinary dice give real variety, and dice loaded almost flat can land on nearly
anything, coherent or not. Top-k and nucleus sampling limit which faces the dice even have, so an
absurd, wildly improbable word never gets a chance to be rolled at all.

## Deep-Dive Explanation

**Greedy decoding and beam search, and why maximizing likelihood backfires.** Greedy decoding is
simply argmax: at each step, choose whichever token the model assigned the highest probability, with
no lookahead. Beam search generalizes this by keeping the top *k* highest-probability partial
sequences (the beam) at every step, expanding every beam's possible next tokens, and pruning back
down to the top *k* overall, approximating the single highest-probability full sequence without
exhaustively searching every possible sequence. Both strategies share the same underlying assumption,
that the best output is the one that maximizes overall sequence probability. Holtzman et al.
([*The Curious Case of Neural Text Degeneration*](https://arxiv.org/abs/1904.09751), 2019) show this
assumption is wrong empirically: real human text is not the maximum-probability continuation at each
point; it carries substantial local unpredictability, and text generated by strictly maximizing
likelihood becomes noticeably repetitive and generic, often looping on the same phrase, because the
model keeps finding that repeating itself is the locally "safest," highest-probability choice.

**Temperature.** Before the final softmax that turns raw model outputs (logits) into a probability
distribution, the logits can be divided by a temperature value T. A temperature below 1 sharpens the
distribution, concentrating probability further onto the already-likely tokens and pushing the
extreme case, T approaching 0, toward greedy decoding. A temperature above 1 flattens the
distribution, giving lower-probability tokens more of a chance and increasing variety at the cost of
coherence once T grows large enough that near-random tokens become plausible picks.

**Top-k and nucleus (top-p) sampling.** Sampling directly from the full vocabulary's distribution
risks occasionally choosing a token far out in the distribution's tail, one the model assigned only a
tiny probability but that is still mathematically possible to sample. Top-k sampling (Fan, Lewis,
and Dauphin, [*Hierarchical Neural Story Generation*](https://arxiv.org/abs/1805.04833), 2018)
addresses this by restricting sampling to only the k highest-probability tokens at each step,
renormalizing their probabilities, and sampling from that fixed-size pool. Nucleus sampling, also
called top-p sampling (Holtzman et al., 2019, the same paper that diagnosed the degeneration problem
above), instead restricts sampling to the smallest set of tokens whose cumulative probability exceeds
a threshold p, then renormalizes and samples from that set. The key difference is that top-k's
candidate pool size is fixed regardless of the shape of the distribution at a given step, while
nucleus sampling's pool size adapts automatically: a sharply peaked distribution (the model is very
confident) yields a small nucleus, while a flatter distribution (genuine uncertainty about several
plausible continuations) yields a larger one. This adaptivity is why nucleus sampling is generally
preferred over a fixed top-k in practice.

**Speculative decoding: a different axis entirely.** Every strategy above answers "which token do we
pick." Speculative decoding (Leviathan et al.,
[*Fast Inference from Transformers via Speculative Decoding*](https://arxiv.org/abs/2211.17192), 2023,
with a concurrent, independently developed version by Chen et al. at DeepMind the same year) instead
answers "how do we produce that same choice faster." A small, cheap draft model proposes several
tokens ahead; the full target model then checks all of those proposed tokens in a single forward
pass instead of one token at a time. Any proposed token that matches what the target model would
have chosen itself is accepted; at the first mismatch, the target model's own choice is substituted
and drafting resumes from there. This is not an approximation: the accept/reject rule is constructed
so the final output distribution is mathematically identical to decoding from the target model alone,
whichever decoding strategy (greedy, temperature-based sampling, nucleus sampling) the target model
was already using. The gain is purely in latency and compute, since the expensive target model runs
fewer, larger, more parallel forward passes rather than one small step at a time.
